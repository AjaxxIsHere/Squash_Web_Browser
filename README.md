# Squash Web Browser

A simple web browser built with [.NET](https://dotnet.microsoft.com/) and [Avalonia UI](https://avaloniaui.net/).

## Prerequisites

Before you begin, ensure you have the following installed:
*   [.NET 9.0 SDK](https://dotnet.microsoft.com/download/dotnet/9.0) or later.

## Getting Started

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/AjaxxIsHere/Squash_Web_Browser.git
    cd Squash_Web_Browser
    ```

2.  **Restore dependencies:**
    ```bash
    dotnet restore
    ```

3.  **Run the application:**
    ```bash
    dotnet run
    ```

## Dependencies

This project uses the following main NuGet packages:

*   [Avalonia](https://www.nuget.org/packages/Avalonia/): A cross-platform UI framework for .NET.
*   [CommunityToolkit.Mvvm](https://www.nuget.org/packages/CommunityToolkit.Mvvm/): A modern, fast, and flexible MVVM library.
*   [HtmlAgilityPack](https://www.nuget.org/packages/HtmlAgilityPack/): An agile HTML parser that builds a read/write DOM and supports plain XPATH or XSLT.
*   [Microsoft.Data.Sqlite](https://www.nuget.org/packages/Microsoft.Data.Sqlite/): SQLite database provider for Entity Framework Core.
*   [Microsoft.EntityFrameworkCore.Sqlite](https://www.nuget.org/packages/Microsoft.EntityFrameworkCore.Sqlite/): SQLite provider for EF Core.
*   **LINQ**: Used extensively for querying in-memory collections and database entities. It is a part of the .NET platform and does not require a separate package.
